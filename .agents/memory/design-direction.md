---
name: App-wide design direction
description: The scope and reference direction for BrightBoard’s visual redesign.
---

The user chose “Entire BrightBoard app,” including public pages and signed-in Teacher Studio, for the Edupath-inspired redesign. Use the light education demo as the reference, not the dark template-selection screen. Keep a white/lavender/violet visual system and preserve the existing React app, real controls, localization, dark mode, and product functionality.

**Why:** The user explicitly wanted an app-wide improvement, while retaining the existing product, and supplied the light Edupath demo as the visual reference.

**How to apply:** Extend the shared visual language to future pages rather than introducing unrelated themes or converting the app to Angular. About should retain the verified founder/company story and describe the full classroom and Teacher Studio product range.

Marketing educator imagery is fictional, not a portrait of the founder.

**Why:** The landing visual was generated as a generic educator image; it must not be misrepresented as an actual person.

**How to apply:** Keep generic educator imagery in marketing contexts, and use only a verified supplied portrait if adding a founder photo.
