Do not show teacher totals, resource totals, or the rotating content showcase on public pages. Preserve the actual creation tools, underlying data, and private owner statistics.

**Why:** The user asked to delete these public sections, saying, "I feel there is no need to be visible to public."

**How to apply:** Future homepage or advertising-page work should not reintroduce these counters or the rotating showcase. Keep usage totals private rather than exposing them through a public endpoint.
