# Changelog

## 1.0.2

- Prepare a version-aligned source and ready-to-run release after updating the
  public repository to match the verified standalone application.
- Keep earlier releases and checksums unchanged. This packaging update retains
  the application features from 1.0.1.

## 1.0.1

- Local `.pptx` import and merge for supported text, embedded images, basic
  shape outlines and private speaker notes, with progress, cancellation and
  explicit compatibility warnings. Existing saved content is not converted.
- Functional accessible presenter-panel collapse/reopen, independently scrolling
  page navigation, and compact responsive editor spacing.
- Hosted page limits of 20 free, 50 standard and 100 institution/business;
  independent standalone uses the free 20-page ceiling without accounts.
- Existing oversized presentations remain recoverable without truncation.
- Presentation size reporting and optional image compression into a separate
  optimized copy, preserving the original presentation.

## 1.0.0

First open-source release: interactive board, multi-page presentation editor,
local saving, portable lesson files, imports/exports, original schematic 3D
models, classroom/presentation tools, installable web app, offline preparation,
and approved phone/tablet control of synchronized audience displays.
